Setup in Anywhere

  1. Confirm the import.
  2. Select your VLESS / chain as the default route and enable Rule mode.
  3. Assign PROXY to the sets marked PROXY. ECH → DIRECT is automatic on first import.
  4. For the ECH preset, place Force Proxy above ReFilter ECH.
  5. Enable Country Bypass → RU for Russian destinations.

ECH receives DIRECT automatically. Select PROXY, the default route and Rule mode in the app. The import link does not change those settings.

Manual import

Use Copy URL to add a set manually. If the app does not open, try Safari.
