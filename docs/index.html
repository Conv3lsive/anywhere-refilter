Открой на устройстве с Anywhere. Выбери схему, добавь наборы и один раз назначь маршруты.

Добавить Re:filter

noECH и IP — через прокси. ECH — напрямую. Force Proxy — исключение для cloudflare-ech.com.

Добавить 4 набора в Anywhere

Один раз в Anywhere

  1. Подтверди добавление наборов.
  2. Выбери свой VLESS / chain основным маршрутом и включи Rule.
  3. В Routing назначь PROXY наборам с этой пометкой. ECH → DIRECT задаётся автоматически при первом добавлении.
  4. В схеме ECH поставь Force Proxy выше ReFilter ECH.
  5. Для российских назначений включи Country Bypass → RU.

Автоматически задаётся DIRECT для ECH. PROXY, основной маршрут и режим нужно выбрать в приложении: импорт-ссылка их не меняет. При обновлении подписок назначения сохраняются.

Если приложение не открылось

Открой страницу в Safari и нажми кнопку добавления. Для ручного импорта используй «Копировать URL» рядом с нужным набором. Уже добавленные подписки достаточно обновить в Anywhere.

Правила на GitHub обновляются ежедневно. Для проверки разрешённого IPv4 по IP-набору выключи Prevent DNS Leak. Подробные настройки и вариант без ECH есть в README.
